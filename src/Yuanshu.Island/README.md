# 元枢内置灵动岛

本目录是元枢主仓库内的桌面显示组件，使用 React、Tauri 和 Rust。它由 DesktopClient 启动，显示元枢语音、任务、媒体和音量状态；用户统一从元枢入口启动、退出、安装和更新。

组件不创建托盘图标，不提供独立安装包或独立登录启动项。直接双击组件程序会提示“请从元枢启动”。`--assistant-settings`、`--show-controls` 和兼容参数 `--settings` 只能激活已运行的内置组件，不能创建脱离元枢的灵动岛。

配置继续使用 Tauri 标识 `com.yuanshu.island` 对应的当前用户配置目录。`preferences.json`、`placement.json` 和隔离 profiles 保持原位置、格式和内容，不复制进代码仓库。助手模式继续使用已交付的拖边收球及全屏保持语音状态可见策略；旧版自动藏边和全屏隐藏偏好原样保留，面板明确标为不适用于助手模式。

任务状态来自 Host 的 Bridge。取消能力必须经过能力协商，并绑定实例、任务和版本；未提供能力时按钮禁用，不推断权限。组件只临时展示助手文字，不持久化文字、音频或凭据。语音、截图、执行和授权边界继续由元枢管理。

主版本统一为 `0.8.0`。正式构建和安装请使用仓库根目录的统一脚本；本目录的 `npm run build`、`npm test`、`cargo test --locked` 仅用于组件开发与检查。`tauri.conf.json` 的 `bundle.active` 固定为 `false`，不另产安装包。
