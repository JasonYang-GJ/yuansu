# 应用搜索提速与发行日期查找

## 本批约定

用户授权优化应用打开、搜索耗时，并要求“最新的歌”按发行资料查找，不能原样当关键词。继续在 `codex/yuanshu`、`e5796b84469a6b9b051e457c6e94de1b0cbce213` 的现有未提交候选上修复；不清理既有修改、不改浮窗位置和录音授权。

普通查询继续沿用原窗口、唯一搜索框、一次提交和结果核验。明确的“歌手 + 最新歌曲”形成独立的发行时间查询语义，与歌手、应用身份、原话一起绑定到本次授权；带引号的文字仍按字面搜索。发行资料查询只访问固定官方公开音乐目录，不使用用户账号、密钥或模型生成的歌曲资料。应用窗口打开后读取发行资料，网络等待结束重新核对窗口及取消状态，只能在本次绑定的窗口输入解析出的曲名。

发行日期按来源地区的日历日期判断，排除未来发行、身份不明和显式再版/现场合集。不把新专辑中重收录的旧作都称为首次发行新歌，不声称目录覆盖全球。网易云目录另以歌手 ID 核实对应曲目；未核到时仍明确报告最新发行作品及日期、执行具体曲名搜索，并说明尚未核实原唱收录，不能把翻唱、同名歌当作成功找到原唱。查询失败不退回把“最新的歌”当普通关键词，也不让普通聊天模型补答案。

## 验收

- 同一真实窗口的搜索框发现耗时前后对照，保留全域唯一性、完整遍历、窗口身份及最终写入验证。
- 冷启动和已打开应用的完整流程分别计时，不用单独函数提速冒充端到端提速。
- 规划、权限绑定、日期排序、艺术家同名、未来发行、重收录、取消和平台未核到分支的定向回归。
- 从隔离 Host 输入原语音转写文本，执行真实网易云搜索；独立读回具体曲名结果，检查发行来源。此项不等于真人麦克风验收。
- 替换固定桌面快捷方式所指候选，核验实际启动、配置/历史/浮窗位置保留。
