# 自由拖动、位置记忆与贴边小球

用户授权本批实现：胶囊自由拖动、重启恢复用户位置、靠近屏幕边缘自动变成吸附小球，拖离边缘恢复胶囊。继续使用当前 Core `e5796b84469a6b9b051e457c6e94de1b0cbce213` 与 Island `36df1f47287227e74b50f1335502b718850df9bb` 工作区已有开发草稿，保留原用户数据及全部历史修改。

## 产品合同

- 胶囊和小球直接响应鼠标：移动超过 4 逻辑像素作为拖动，否则单击打开原操作面板。拖动不得触发点击、开始语音、停止或其它任务动作。
- 胶囊 224×28，小球 44×44；距所在显示器工作区任意一侧不超过 24 逻辑像素时松手，变球并贴边留 4 逻辑像素。拖离后恢复胶囊；四角确定选择最近边。球保留麦克风状态提示。
- 手动面板空白标题区域可拖，按钮、正文选择和滚动不触发拖动。自动文字面板仍穿透；显式打开才接受操作。
- 只在明确拖动结束时保存显示器、相对工作区位置和停靠边。自动展开、缩回、语音状态和其它窗口变化不能改写用户位置。Esc 取消拖动恢复起点且不保存。
- 重启恢复，DPI/工作区变化时约束在可见区域；原显示器消失则恢复到可用显示器。损坏的位置文件不阻止启动，给出可理解的提示。

## 实现与边界

Island 原生层拥有位置、停靠和拖动状态。主窗口限定的 `assistant_begin_drag` 验证真实左键按住与指针位于自身可拖区域，调用本机窗口拖动；`assistant_open_controls` 只打开现有面板。`assistant_placement_state` 与 `assistant-placement-changed` 使用单调 revision，字段为 mode、edge、dragging、error。mode 代表休息形态；前端控制器仍使用 compact/expanded，避免与独立 Island 的四态策略互相覆盖。

位置文件单独保存在当前用户 Island 配置目录，沿用现有隔离 profile；不写入项目仓库，不修改 Provider 凭据和聊天数据。自动展开与显示确认继续依赖真实窗口完成及最终文字绘制；拖动时只为已显示版本续可见心跳，不得确认尚未显示的新指令。隐藏、失联和停止仍取消原请求。

## 验收计划

原生几何/保存回读/损坏输入/负坐标/DPI/缺失显示器/显式拖动边界测试；前端拖动与点击区分、球形态、旧状态拒绝、按钮与文本不拖动、展示回执测试。独立测试配置运行真实原生拖动、贴四边、拖离、Esc 撤销、重启恢复和语音显示；测试只操作自己的窗口。最终生产构建、桌面入口与原运行数据保留检查。结果保存在 `<private-evidence>/assistant-island-drag-20261011`，真实麦克风听感不以模拟替代。

## 已验证结果（2026-10-11）

- 原生 65 项、前端 151 项、DesktopClient 177 项测试通过；严格原生静态检查、前端生产构建和真实窗口测试工具 Release 编译通过。
- 独立浏览器检查真实前端布局、麦克风图标及关闭斜线、键盘打开、鼠标拖动不误开面板。所有内容来自测试数据。
- 真实 Windows/Tauri/WPF 测试首次 11 项全通过，35.7 秒，正常退出并还原指针：自由拖动、四边贴球、拖离胶囊、新进程恢复球位置、短按球打开面板、标题拖动、手动面板拖动 Esc 撤销且文件不变、4 秒逐步转写期间拖动心跳不中断、自动展开不覆写保存位置、最终转写真实展示后只提交一次、拖动/展开不擅自启动或停止麦克风。
- 随后真实交付检查发现短点击后收起仍占前台的问题：WebView 可能先取得焦点，之后的读取丢失了原窗口。现由自有原生窗口激活消息记录原窗口身份，打开面板不再用空结果清除记录；休息态拖动完成亦归还焦点，仅在当前前台仍为自身且原窗口身份有效时恢复，不干扰用户已切换的其它窗口。
- 增强的真实测试最终 13 项全通过，34.9 秒（`island-drag-5.log`）：在原 11 项上增加拖动后、短点击展开并收起后精确归还原测试窗口。第 2–4 次运行的测试前置条件曾失败：启动/重开后原测试窗口并不总是前台。现每个相关场景先在自有测试窗口上真实点击建立前置条件；未放宽任何操作后的焦点断言，保留所有失败日志。
- 测试使用隔离 profile、受控语音输入和测试 Provider；它验证真实原生窗口及实际 Host 提交链，不替代真人麦克风、语音识别或播报听感验收。视觉记录 `visual-review.md`。
- 最终原生程序 SHA-256：`E1043A6B5DDE23E89C5B13695F9861488A10B7269CD9E34498884156EE392294`；76 个构建输入前后相同，详见 `native-build-inputs.json` / `native-release-identity.json`，首次版本保留于 `first-native-*`。本批基于已有开发草稿，不是干净冻结发布。

## 边界

- 显示器布局/DPI 检测沿用现有 750 毫秒周期，只在变化时约束位置，拖动中不干扰且不保存。多屏负坐标、DPI 与缺失显示器已做几何回归；真实多屏热拔插尚未测试。
- Esc 真实验收覆盖手动面板拖动，休息态拖动的 Esc/前台焦点行为未独立实测。
- Core 最终文字展示期限仍为 3 秒。若完整语音指令恰在拖动中到达且持续超过期限，仍安全取消并暂停收音，不执行未展示的指令；本批未放宽此边界。普通逐步转写在松手后继续显示，已实测。
- 桌面快捷方式、运行实例及原配置/历史保留检查的最终结果记录于同一外部证据目录的 `delivery-entry.json`、`runtime-after.json` 和 `acceptance.md`。
