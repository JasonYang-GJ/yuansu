# 应用搜索连续流程（开发候选）

本批承接用户 2026-10-11 的继续开发授权，优先完成软件打开、搜索、结果检查与明确请求的后续操作；之后依次处理唤醒、文件查找、记忆。当前基于 `codex/yuanshu` 的 `e5796b84469a6b9b051e457c6e94de1b0cbce213` 和已有未提交的桌面助手修复草稿，保留用户配置及历史。

## 行为与边界

- 一句“打开我的网易云，然后搜索周杰伦”或“在我的抖音里搜索 AI 编程”形成一个原始 Turn。
- 自然口语“桌面上的网易云然后搜索周杰伦最新的歌”也进入同一执行流程；支持省略“打开”、有限的重复“给我”，以及通用桌面修饰语。明确的应用搜索序列不再被当成整段桌面文件名；引用、否定、讨论、文件名和完整注册应用名仍保留各自边界。
- 使用已有安装应用目录解析名称，绑定真实应用 ID、启动目标、原始搜索词及后续动作；不通过模型授予权限，不退回任意网页。
- 后续动作限明确请求的第一条媒体结果打开 / 第一首播放。默认只搜索；不能由结果页面里的文字授权后续动作。
- 依次验证目标应用窗口、唯一搜索框、精确写入、单次提交、结果页；结果不可验证则准确说明已完成的步骤。
- 仅在可靠媒体结果容器里调用系统控件动作，不移动指针，不猜坐标，不发送消息或操作账号、付款、删除。
- 用户停止、替换输入或目标变化时中断，重启不重放；等待确认后重新规划须核对完整目标。

## 实现

`DeterministicIntentPlanner` 解析明确句式，`SessionCoordinator` 保持唯一会话/任务状态，`AssistantCommandService` 冻结目标，经 `CapabilityPolicyEngine` 的一次性 `ApplicationSearch` 作用域进入 `WindowsDesktopSkillAdapter`。原生执行层复用可信应用启动和可靠搜索，增加结果语义检查。沿用现有 IPC 与数据库字段，不新增并行任务状态或远程控制。

## 验收

先复现旧行为，再检查语言歧义、一次授权、目标漂移、取消、晚结果、重启不重放、未知结果拒绝后续。真实低风险搜索验收与模拟测试分开记录；网易云 / 抖音只有真实操作通过后才列为可用。不将搜索提交等同于已找到或播放结果，不把候选版写成正式发布。

### 已确认的实机事实

- 在隔离运行目录内，通过实际 DesktopHost/Session 的“打开我的网易云，然后搜索晴天”和“打开我的网易云，然后搜索周杰伦”，均到达 `Completed`。确认覆盖应用目标、输入、单次提交和对应的真实单曲结果；没有调用普通聊天模型，也没有截图或开启麦克风。
- 网易云的 Chromium 搜索输入不支持常规 `SetFocus`，且写入后的值和宽度异步更新。本批使用与唯一原生搜索输入绑定的控件动作取焦，再等待精确值回读；不重复写入，不猜坐标。
- 网易云结果读取限定于实际 `page_pc_search_result` 子树、独立查询文本和单曲卡片。不同查询要求结果内容更新；同关键词重复搜索可确认当前显示结果，不声称刷新或“最新”。多歌手作者分隔符不再被误认作第二个标题。
- 在相同隔离 Host 中，“打开我的抖音，然后搜索美食”和随后“打开我的抖音，然后搜索风景”均到达 `Completed`，分别约 12.4 秒和 12.2 秒。通过真实应用独立搜索页地址中的关键词及视频结果容器确认；变更关键词还核对首条视频身份更新。未调用聊天模型、截图或开启麦克风。
- 抖音会在搜索结果页自动显示视频。这个软件自身行为不算元枢执行了“打开第一条 / 播放第一条”；本批读取的媒体结果凭据不可执行动作，作者主页链接也不能当作视频链接调用。
- 搜索后的“播放第一首 / 打开第一条”已接入受控流程及拒绝/取消测试，但网易云尚未提供经本批证实的稳定媒体身份和明确操作，因此没有真实播放通过证据。不能将框架或模拟媒体控件测试说成真实软件已支持。

### 同批修复的请求顺序

客户端撤销输入后继续等待有限时长的 Host 回执，拿到精确 Session/Turn 后取消；语音、文字、新话题及选中操作的登记共享这一交接边界。无法确认旧请求已停止时，不静默提交下一项。相关测试扣住真实 Client 的提交回执，覆盖登记前被替换、已收到回执但取消尚未完成、停止与新话题竞争。测试使用假语音和假模型，不能替代真人语音验收。

### 尚未完成

任意第三方软件的搜索、媒体播放与多步骤操作不构成通用保证。网易云和抖音的自动媒体后续操作、真实无结果页尚未取得本批实机通过证据；不能把无法验证结果说成没有结果。唤醒词待命、桌面部分名称查找以及助手内记忆入口已继续实施，具体实测层级见[后续功能记录](ASSISTANT_FOLLOWUP_20261011.md)。真实麦克风、真人播报感受和指针问答仍保留单独验收边界。正式分发、签名及干净版本冻结不属于本批交付。
