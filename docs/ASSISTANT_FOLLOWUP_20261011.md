## 后续改动范围

- 语音待命保留启动后直接对话的入口。明确休息命令才进入待命；待命仍使用本机麦克风和离线识别，界面必须明确显示。普通谈话不提交给 Host 或聊天模型；精确唤醒词恢复原话题。暂停、退出继续关闭麦克风。识别代际与 Session 状态分离，不建立第二个会话。
- 查找桌面文件仅枚举用户/公共桌面第一层文档名称，不读文件正文、不递归。查找和打开分别表达：查找只列结果；打开唯一匹配项仍需逐文件确认，重名交由用户选择。确认前后核对所选文件、范围及元数据，不允许选择器绕过原请求。
- 小球增加“记忆”按钮，直接定位现有本机记忆面板。沿用显式保存、修正、停用、删除及本次聊天选择/完整出站确认。打开入口本身不保存、选择或发送记忆，不自动提取用户画像。

## 使用方式

- 默认双击桌面“元枢”进入小球和直接语音对话。管理页按需打开。
- “打开我的网易云，然后搜索周杰伦”“打开我的抖音，然后搜索风景”：在唯一可靠搜索框中输入，提交后核对对应结果。搜索过程中请保持目标软件在前台；窗口变化会停止操作。
- “帮我找一下桌面上的会议记录”：仅查找桌面文档；“打开桌面上的会议记录”：确认精确文件后才打开。范围不包括全盘、子目录、程序或快捷方式。
- 单独说“先休息”或“退下”进入本地待命；此时麦克风仍开启，只在本机等待唤醒。单独说“元枢”或“你好元枢”，听到“我在，请说”后再说指令。当前不把“元枢打开微信”作为待命唤醒与动作的组合指令。
- 小球“暂停语音”或 Esc 关闭麦克风；重新点击开始后恢复直接对话。
- 点击小球“记忆”管理明确保存的内容；不会自动整理聊天或自动把记忆发给模型。
