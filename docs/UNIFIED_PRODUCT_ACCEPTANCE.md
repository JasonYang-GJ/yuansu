## 验收过程中发现和修正的问题

1. 正常入口继承旧的全局数据环境变量，可能指向非当前使用的数据目录：加入本机路径配置与继承值识别，显式隔离测试环境继续优先。
2. 旧搜索焦点实验尚未交付：使用此前实际桌面版的已验收实现，原实验完整差异保留在 [实验记录](experiments/README.md)。
3. 元枢和安装器启动项名称不一致：统一使用 `ScreenGuideDesktop`，仅迁移经过身份验证的旧岛启动命令。
4. 安装验收仅等待原始卸载进程，早于第二阶段完成就检查注册表/目录：改为等待本次成功日志关闭并验证实际文件和登记移除。前两轮失败及日志原样保留，不能算作通过。
5. 首轮媒体测试工具没有发布 Windows 桌面媒体会话：用当前进程窗口绑定原生媒体控制后，先独立核验系统会话存在，再验证岛界面显示。依据 [Windows 桌面媒体控制接口](https://learn.microsoft.com/en-us/windows/win32/api/systemmediatransportcontrolsinterop/nf-systemmediatransportcontrolsinterop-isystemmediatransportcontrolsinterop-getforwindow)。未为此修改产品媒体代码。
