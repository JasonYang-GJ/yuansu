## 产品和实现边界

- 灵动岛源码纳入 `src/Yuanshu.Island`，导入来源与逐文件摘要见 `imports/ISLAND_SOURCE_IMPORT.json`。原仓库保留作历史存档，构建不读取它。
- 元枢为唯一用户入口与托盘所有者。灵动岛是同版本的内置窗口子进程，由元枢启动、连接和退出；保留多进程隔离，不以“只有一个进程”作为合并标准。
- 语音、对话、任务和桌面操作仍由原 SessionCoordinator 与权限边界执行。灵动岛继续呈现助手、任务、媒体、音量和位置设置，不获得新的执行权限。
- 普通启动、更新后启动和开机启动均先暂停语音，用户在可见窗口中开始语音。旧 `--assistant` 显式语音入口保留兼容。缺失或断开的岛组件必须可见报错、停止语音。
- 使用原安装 AppId 和安装目录。一个安装包携带 Client、Host 和 Island；旧版升级不删除数据，卸载也保留数据。旧独立岛不再单独构建或安装。
- 保留 `%APPDATA%/com.yuanshu.island` 原设置身份。主数据目录默认保持原值；已有自定义数据/模型目录使用本机用户配置指向原位置，不移动数据库、不重新创建凭据。
- 历史候选中未交付的搜索性能实验不得悄悄替换已使用行为；保留实验源码证据，以现有已验收源码为合并基线。

## 写入分工

主执行流负责 Client 启动、数据路径继承、版本、统一构建与端到端交付。独立流负责 `src/Yuanshu.Island`；安装流负责 Inno 安装定义及隔离环境生命周期检查。任务取消桥先只读比对后按明确文件所有权移植。

## 验收标准

1. 从本仓库锁定依赖构建全部组件，版本一致，输出单个安装包和源文件/产物摘要，不借用旧发布二进制。
2. 受影响边界测试、C# 回归、Island React/Rust 测试和构建通过；真实 Release 窗口与托盘只有一个入口。
3. 正常、管理、后台及重复启动均连接同一产品；暂停启动不打开麦克风，退出关闭三个组件；媒体/音量与任务呈现可用。
4. 隔离 Windows 环境验证旧版安装、升级、卸载、重装及数据哨兵保留，不在用户电脑上做卸载试验。
5. 更新用户真实入口后核验路径、版本、进程、单托盘，以及原数据库记录数、配置/凭据摘要和岛位置设置。证据放在仓库外，禁止保存或提交真实对话正文、凭据或截图。
