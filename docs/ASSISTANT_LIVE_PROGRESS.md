用户授权继续优化首个可见打开动作及完整搜索耗时，修复“打开网易云，搜索最近周杰伦的新歌”被当作聊天，并要求在灵动岛显示真实执行步骤。

边界和实现约定：

- 受限口语前缀及“最近/新歌”通过确定性规划识别；无明确动作的音乐片段简短澄清，不从旧聊天猜测操作权限，不把语音错字“我见到”改成“打开”。
- 同一识别代际内、短时间、明确打开/搜索链的语音分段允许临时组句；普通交谈不拼接，不增加所有输入的固定等待。停止、不同输入、停听或识别代际变化即失效。
- 优先打开并验证目标窗口，再同步预热搜索框并异步读取发行资料，提交前仍重新验证实际窗口、唯一控件、输入值和授权。
- Windows 执行层报告有限枚举阶段；Host 仅在当前执行调用范围内关联到原 Turn，经 SessionCoordinator 检查 Turn/Operation/取消及终态后写现有 ResultSummary。现有 session delta 将其投影到灵动岛，不增加第二套任务状态、数据库字段或 IPC 协议。
- 开始、窗口打开、查发行资料、搜索、检查结果必须来自真实执行边界；不得用定时动画伪装进度。来源仍为公开发行目录，不能冒充全球首次发行或平台原唱。

验收将包含规划分支、真实 Client 分段接收、进度隔离/取消/迟到/重启、实际窗口首开时间及完整耗时、真实 Release 灵动岛状态显示、固定桌面入口与数据保留。假识别测试不代替真人麦克风验收。

复现根因：本机语音接收将明确搜索句拆为两个最终片段，第二段替换了前段；“就是请帮我”和“最近…新歌”亦未覆盖。修复保留明确连接的原文，不修造动作：识别成“我见到桌面上的网易云然后搜索…”时短澄清，不能擅改为打开。不能据此诊断已配置 API 不可用。
